1.加一个基于之前轨迹的优化器

T_prior

现在更像是：

1. GLIM map 本身大体跟 Atlas INS 走；
2. GICP 的 prior/observer 在弯道偏离 Atlas INS；
3. scan matching 在弯道/退化结构里不能可靠把它拉回正确 basin；
4. gating 只能阻止部分坏 candidate，但不能修坏 prior；
5. snap 是 recovery，不是 localization 本体。

偏离后没回 INS，主要是这个逻辑：

```
bad prior -> GICP 在 wrong basin 找到局部低残差解 -> accepted
accepted -> current_pose/basePose/observer 被写成 GICP 结果
accepted -> consecutive_failures 清零
consecutive_failures 不够 -> snap 不触发
所以不会回 INS
```
