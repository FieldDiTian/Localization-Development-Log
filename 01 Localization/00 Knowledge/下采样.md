当前代码用的是 PCL 的 `VoxelGrid`，不是随机采样。

`VoxelGrid` 的逻辑是：

```
把空间切成一个个小立方体 voxel
每个 voxel 里面可能有很多点
用这些点的质心/平均点代表整个 voxel
```

比如 leaf size 是 `0.3m`，那么空间被切成：

```
0.3m x 0.3m x 0.3m
```

如果某个格子里有 15 个 map 点，它不会保留 15 个，只保留一个代表点：

```
representative_point = 这 15 个点的平均位置
```
